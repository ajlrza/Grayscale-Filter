# Grayscale-Filter
An OpenCV script for a camera Grayscale filter

# About
Uses OpenCV library to manipulate image color pixels from local camera into grayscale

# How to Use
1. Run python file
2. Press 'G' - Gray scale, 'F' - RGB image, 'C' - exit
